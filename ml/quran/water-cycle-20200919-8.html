ജലചക്രം

Unknown · 2020-09-19 · Quran & Tafsir

“അങ്ങനെ അത്(വെള്ളം) കൊണ്ട് നാം നിങ്ങൾക്ക് ഈത്തപ്പനകളുടെയും മുന്തിരിവള്ളികളുടെയും തോട്ടങ്ങൾ വളർത്തിത്തന്നു. അവയിൽ നിങ്ങൾക്ക് ധാരാളം പഴങ്ങളുണ്ട്. അവയിൽനിന്ന് നിങ്ങൾ തിന്നു കൊണ്ടിരിക്കുകയും ചെയ്യുന്നു”(23:19).

നിരവധി ഖുർആൻ വചനങ്ങളിൽ ഇതുപോലെ ആകാശത്തുനിന്ന് മഴ വർഷിപ്പിക്കുകയും അതുമൂലം സസ്യലതാദികൾ മുളപ്പിച്ച് ഭൂമിയെ ജീവനുള്ളതാക്കിത്തീർക്കുകയും അതിൽ ജന്തുജാലങ്ങളെ വ്യാപിപ്പിക്കുകയും ചെയ്തു എന്ന അനുഗ്രഹം ആവർത്തിച്ചാവർത്തിച്ച് പ്രഖ്യാപിക്കുന്നത് കാണാനാവുന്നത്.

“മടങ്ങി വരുന്ന കാര്യം ഉൾക്കൊള്ളുന്ന ആകാശം തന്നെയാണ് സത്യം” (ഖുർആൻ 86:11).

‘റജ്അ്’ എന്ന അറബി പദത്തിനർഥം ‘മടങ്ങി’ എന്നാണ്. അഥവാ ഒരു സ്ഥലത്തേക്ക് പോയാൽ അവിടുന്ന് തിരിച്ചു മടങ്ങിവരിക. റിട്ടേൺ (return) എന്ന് ഇംഗ്ലീഷിൽ പറയും. ‘അർജഅ്’ എന്നാൽ ‘മടങ്ങിവരുന്ന വസ്തു’ എന്നുമാണ് അർഥം.

ജലചക്രം ചിത്രീകരിക്കുന്ന ചിത്രം

“തന്റെ കാരുണ്യത്തിന്റെ മുമ്പിൽ സന്തോഷസൂചകമായി കാറ്റുകളെ അയച്ചും അവനത്രെ. ആകാശത്തുനിന്ന് ശുദ്ധമായ ജലം നാം ഇറക്കുകയും ചെയ്തിരിക്കുന്നു”(25:48).

“നിർജീവമായ നാടിന് അതുമൂലം നാം ജീവൻ നൽകുവാനും നാം സൃഷ്ടിച്ചിട്ടുള്ള ധാരാളം കന്നുകാലികൾക്കും മനുഷ്യർക്കും അത് കുടിപ്പിക്കുവാനും വേണ്ടി”(25:49).

“ആകാശത്തുനിന്ന് നാം അനുഗ്രഹീതമായ വെള്ളം വർഷിക്കുകയും എന്നിട്ട് തോട്ടങ്ങളും കൊയ്തെടുക്കുന്ന ധാന്യങ്ങളും നാം മുളപ്പിക്കുകയും ചെയ്തു”(50:9).

“അവനാണ് ആകാശത്തുനിന്ന് വെള്ളം ചൊരിഞ്ഞുതന്നത്. അതിൽനിന്നാണ് നിങ്ങളുടെ കുടിനീർ. അതിൽനിന്നുതന്നെയാണ് നിങ്ങൾ (കാലികളെ) മേയ്ക്കുവാനുള്ള ചെടികളുമുണ്ടാകുന്നത്”(16:10).

“അത് (വെള്ളം) മൂലം ധാന്യവിളകളും ഒലീവും ഈത്തപ്പനയും മുന്തിരികളും നിങ്ങൾക്ക് മുളപ്പിച്ചുതരുന്നു. എല്ലാതരം ഫലവർഗ്ഗങ്ങളും (അവൻ ഉൽപാദിപ്പിച്ചിട്ടുമുണ്ട്). ചിന്തിക്കുന്ന ആളുകൾക്ക് തീർച്ചയായും അതിൽ ദൃഷ്ടാന്തമുണ്ട്” (16:11).

The sky which returns എന്നുപറഞ്ഞാൽ ‘മടങ്ങി വരുന്ന സംഭവം ഉള്ളതായ ആകാശം’ എന്നാണ് അർഥം. എന്താണ് ഈ ഒരു പദംകൊണ്ട് ഉദ്ദേശിക്കുന്നത് എന്ന് നമ്മൾ പരിശോധിച്ചാൽ നമുക്ക് ഖുർആൻ വ്യാഖ്യാന ഗ്രന്ഥങ്ങളിൽ (തഫ്സീറുകളിൽ) കാണാൻ കഴിയുന്നത് ആകാശത്തുനിന്നും മേഘങ്ങളിൽനിന്നും ഭൂമിയിലേക്ക് മഴ വർഷിക്കുകയും തിരിച്ച് ഭൂമിയിൽ നിന്നും വെള്ളം നീരാവിയായി, മേഘങ്ങളായി ആകാശത്തേക്ക് മടങ്ങിപ്പോവുകയും ചെയ്യുന്നത് എന്നാണ്.

‘വസമ്മാഇ ദാതിർജഅ്’ എന്നതിന് ഖുർആൻ തഫ്സീറുകളിൽ എല്ലാം ഈയൊരു വിശദീകരണം തന്നെയാണ് നൽകപ്പെട്ടിട്ടുള്ളത്. പ്രമുഖ സഹാബിയും (പ്രവാചക ശിഷ്യൻ) ഖുർആൻ വ്യാഖ്യാതാവും ആയ അബ്ദുല്ലാഹിബ്നു അബ്ബാസ് ഈ ഒരു ആയത്ത് വിശദീകരിച്ചിട്ടുള്ളത് ‘ആവർത്തിച്ചാവർത്തിച്ച് മഴപെയ്യുന്ന മഴമേഘങ്ങൾ’ എന്നാണ്. ആകാശത്തുള്ള മേഘങ്ങളിൽനിന്ന് മഴയുണ്ടാകുന്നു. അങ്ങനെ ഭൂമിയിലെത്തിയ വെള്ളം തിരിച്ചു മേഘങ്ങളായി ആകാശത്തേക്ക് തന്നെ മടങ്ങുന്നു. വീണ്ടും ആവർത്തിച്ച് മഴപെയ്യുന്നു. വീണ്ടും തിരിച്ചു പോകുന്നു. ഇങ്ങനെ ആവർത്തിച്ചുകൊണ്ടിരിക്കുന്ന ഈയൊരു വാട്ടർ സൈക്കിളിനെ വളരെ കൃത്യമായ, ചുരുങ്ങിയ പദങ്ങൾകൊണ്ട് വിശദീകരിച്ചത് എത്ര അത്ഭുതകരമെന്ന് നോക്കൂ. ഖുർആനിലെ പദപ്രയോഗങ്ങൾ നമ്മെ അത്ഭുതപ്പെടുത്തുന്നത് ഇങ്ങനെയൊക്കെയാണ്.

സമുദ്രങ്ങളിൽനിന്നും മറ്റു ജലാശയങ്ങളിൽനിന്നുമൊക്കെ വെള്ളം ഓരോ സെക്കന്റിലും നീരാവി

യായി അന്തരീക്ഷത്തിലേക്ക് പോയിക്കൊണ്ടിരിക്കുകയാണ്. മാത്രമല്ല മനുഷ്യനും മറ്റു ജീവജാലങ്ങളും സസ്യങ്ങളും ശ്വസിക്കുമ്പോഴും, അടുക്കളയിൽ വെള്ളം തിളപ്പിക്കുമ്പോഴുമെല്ലാം ജലം നീരാവിയായി അന്തരീക്ഷത്തിലേക്ക് പോയിക്കൊണ്ടേയിരിക്കുകയാണ്. Evaporation അഥവാ ബാഷ്പീകരണം എന്നാണ് ഇത് അറിയപ്പെടുന്നത്. ഇപ്രകാരം ബാഷ്പീകരണത്തിന്റെ ഫലമായി ഉണ്ടാകുന്ന നീരാവിയുടെ സാന്ദ്രത അന്തരീക്ഷത്തിലെ പ്രധാന വാതകങ്ങളായ നൈട്രജൻ, ഓക്സിജൻ എന്നിവയെക്കാൾ കുറവായതുകൊണ്ട് തന്നെ ഈ നീരാവി സ്വാഭാവികമായി മുകളിലേക്ക് ഉയർന്നുപൊങ്ങും. മുകളിൽ എത്തുന്ന നീരാവി അന്തരീക്ഷമർദ്ദം കുറയുന്നതിന്റെ ഫലമായി തണുക്കുകയും വളരെ ചെറിയ ജലകണങ്ങൾ ആയി മാറുകയും ചെയ്യുന്നു. ഇത്തരത്തിൽ വളരെ ചെറിയ ജലകണങ്ങൾ ചേർന്നാണ് മേഘം ഉണ്ടാവുന്നത്. വാതക അവസ്ഥയിലുള്ള നീരാവി ദ്രാവകാവസ്ഥയിലുള്ള ചെറിയ മേഘകണികകൾ ആവാൻ നീരാവി തണുത്താൽ മാത്രം പോരാ; അതിനു വളരെ ചെറിയ ചില കണികാ പദാർത്ഥങ്ങളുടെകൂടി ആവശ്യമുണ്ട്. Cloud condensation nuclei അല്ലെങ്കിൽ cloud seeds എന്നറിയപ്പെടുന്ന വളരെ ചെറിയ പൊടിപടലങ്ങളുടെ രൂപത്തിലുള്ള കണികകൾ മേഘങ്ങളുടെ രൂപീകരണത്തിന് അത്യാവശ്യമാണ്. 0.2 മൈക്രോൺ വലിപ്പമുള്ള ഇത്തരം cloud seeds അഥവാ മേഘവിത്തുക്കൾ എന്നറിയപ്പെടുന്ന കുഞ്ഞുകണികകൾ ഉണ്ടെങ്കിൽ മാത്രമേ വാതകാവസ്ഥയിലുള്ള നീരാവി ഘനീഭവിച്ച് ദ്രാവകാവസ്ഥയിലോ മഞ്ഞ് അവസ്ഥയിലോ ആയി മാറുകയുള്ളൂ.

കാറ്റിൽ അടങ്ങിയിരിക്കുന്ന പൊടിപടലങ്ങൾ, പുക എന്നിവയൊക്കെയാണ് ഇത്തരം cloud സീഡുകളായി അഥവാ മേഘവിത്തുക്കളായി പ്രവർത്തിക്കുന്നത്. അഥവാ അന്തരീക്ഷത്തിൽ ഉയർന്നുപൊങ്ങി മുകളിൽ എത്തുന്ന നീരാവി കാറ്റിന്റെ സഹായത്തോടുകൂടി അവിടെയെത്തുന്ന 0.2 മൈക്രോൺ വലിപ്പമുള്ള മേഘവിത്തുക്കൾ എന്നറിയപ്പെടുന്ന കുഞ്ഞൻപൊടിപടലങ്ങളുമായി കൂടിച്ചേരുമ്പോഴാണ് മഴമേഘം ഉണ്ടാവുന്നത്. കഴിഞ്ഞ നൂറ്റാണ്ടിൽ മാത്രം കണ്ടുപിടിക്കപ്പെട്ട ശാസ്ത്ര സത്യങ്ങളാണിത്! നമ്മളിൽ തന്നെ ബഹുഭൂരിപക്ഷം ആളുകളും cloud condensation nuclei അല്ലെങ്കിൽ cloud seeds എന്നൊന്നും കേട്ടിരിക്കാൻ പോലും സാധ്യതയില്ല. ഒരുപക്ഷേ, ഇത് വായിക്കുന്നവരിൽ പലരും cloud seed അല്ലെങ്കിൽ ‘മേഘവിത്ത്’ എന്നൊക്കെ ആദ്യമായി കേൾക്കുന്നവരായിരിക്കും.

പറഞ്ഞുവന്നത് ഇതാണ്; അന്തരീക്ഷത്തിൽ നീരാവി ഉണ്ടായാൽ മാത്രം പോരാ, കാറ്റിന്റെ സഹായത്തോടെ ആ നീരാവി പാളികളിൽ മേഘവിത്തുക്കൾ വിതറപ്പെടണം. എങ്കിൽ മാത്രമേ നീരാവി ഘനീഭവിച്ച് മഴമേഘങ്ങൾ രൂപപ്പെടുകയുള്ളൂ, മഴ പെയ്യുകയുള്ളൂ. ഇന്നും ശാസ്ത്രലോകത്തിനു പൂർണ്ണമായ രൂപത്തിൽ മേഘവിത്തുക്കളെക്കുറിച്ച് അറിയില്ല എന്നതാണ് വാസ്തവം. ഇപ്പോഴും പരീക്ഷണ നിരീക്ഷണങ്ങൾ നടന്നുകൊണ്ടിരിക്കുന്ന ഒരു മേഖലയാണിത്. ക്ലൗഡ് സീഡിങ് വഴി കൃത്രിമ മഴ പെയ്യിക്കാനുള്ള ശ്രമങ്ങൾ പലരാജ്യങ്ങളും നടത്തിക്കൊണ്ടിരിക്കുന്നുണ്ട്. കഴിഞ്ഞ ഏതാനും വർഷങ്ങളിൽ യു.എ.ഇ പ്രത്യേകം വിമാനങ്ങൾ ഉപയോഗിച്ചുകൊണ്ട് മേഘങ്ങളുടെ മുകളിൽ ഇത്തരം മേഘവിത്തുക്കൾ വിതറിക്കൊണ്ട് കൃത്രിമ മഴ പെയ്യിക്കാനുള്ള ശ്രമങ്ങൾ നടത്തിയതും ചെറിയതോതിൽ ആ ശ്രമങ്ങൾ വിജയിച്ചതും എല്ലാം നമ്മൾ വാർത്തകളിൽ വായിച്ചതാണ്. (അവസാനിച്ചില്ല).

‘വസ്സമാഇ ദാതിർജഅ്’ എന്നതിന് ഖുർആൻ തഫ്സീറുകളിൽ എല്ലാം ‘മടങ്ങിവരുന്ന സംഭവം ഉള്ളതായ ആകാശം’ എന്ന വിശദീകരണം തന്നെയാണ് നൽകപ്പെട്ടിട്ടുള്ളത്. പ്രമുഖ സഹാബിയും ഖുർആൻ വ്യാഖ്യാതാവും ആയ അബ്ദുല്ലാഹി ബ്നു അബ്ബാസ് (റ) ഈ ഒരു ആയത്ത് വിശദീകരിച്ചിട്ടുണ്ട്. ‘ആവർത്തിച്ചാവർത്തിച്ച് മഴപെയ്യുന്ന മഴമേഘങ്ങൾ’ എന്നാണ്. ആകാശത്തുള്ള മേഘങ്ങളിൽനിന്ന് മഴയുണ്ടാകുന്നു. അങ്ങനെ ഭൂമിയിലെത്തിയ വെള്ളം തിരിച്ചു മേഘങ്ങളായി ആകാശത്തേക്ക് തന്നെ മടങ്ങുന്നു. വീണ്ടും ആവർത്തിച്ച് മഴപെയ്യുന്നു. വീണ്ടും തിരിച്ചുപോകുന്നു. ഇങ്ങനെ ആവർത്തിച്ചുകൊണ്ടിരിക്കുന്ന വാട്ടർ സൈക്കിളിനെ വളരെ കൃത്യമായ, ചുരുങ്ങിയ പദങ്ങൾകൊണ്ട് വിശദീകരിച്ചത് എത്ര അത്ഭുതകരമെന്ന് നോക്കൂ. ഖുർആനിലെ പദപ്രയോഗങ്ങൾ നമ്മെ അത്ഭുതപ്പെടുത്തുന്നത് ഇങ്ങനെയൊക്കെയാണ്.
